Modelar la salida

Separador: modelar la salida.

Un catálogo para elegir sin dudar

Clave para el examen

Catálogo: real → 1 lineal + MSE; sí/no → sigmoide + BCE; N clases → softmax + CE; percentiles → pinball. La tarea fija la salida.

Palabras clave
Capa de salida (par activación–loss)MSE (y sus alternativas MAE y Huber)Entropía cruzada (BCE y cross-entropy)

La capa de salida la determina la tarea

En la salida la activación define rango e interpretación: lineal (todo ℝ), sigmoide (0,1), softmax (suma 1), softplus (≥0).

Palabras clave
Capa de salida (par activación–loss)SigmoideSoftmax

Cómo se ven las cuatro

Las formas explican el uso: la lineal no tiene techo (precio), la sigmoide sí (probabilidad), softplus tiene piso (conteos).

Palabras clave

BCE: $-[t\log y+(1-t)\log(1-y)]$. Como $t$ es 0 o 1, siempre queda un solo término vivo.

Cross-entropy multiclase: $L=-\log y_c$, solo mira la probabilidad de la clase correcta (0,80 → 0,22; 0,05 → 3,00).

Buscar el mínimo de una función

Qué es backpropagation, y de dónde salió

Clave para el examen

Backprop calcula el gradiente de todos los pesos en una pasada hacia atrás; el aprendizaje en sí es el descenso por gradiente.

Palabras clave

Entrenar es un ciclo de dos movimientos

Forward predice; backward anota cuánto culpa tiene cada peso. Los pesos todavía no se mueven: se acumula.

La tasa de aprendizaje η

Cerrado el batch, $w\leftarrow w-\eta,\nabla$. η es uno de los hiperparámetros más sensibles; puede terminar en un mínimo local.

El learning rate es el paso

Diagnóstico: si la loss oscila, η es grande; si baja plana y no llega, es chico.

Palabras clave

Batch y época no son lo mismo

Clave para el examen

El train se parte en batches; cada batch produce un ajuste. Una época = tantos ajustes como batches (10.000 filas, batch 100 → 100).

El ciclo completo, batch a batch

Dentro del batch se acumula, al cerrarlo se aplica. El batch size cambia cuántos ajustes hay y cuánto ruido trae cada uno.

Palabras clave

La función objetivo

Clave para el examen

Se minimiza $J=\text{cost}+\lambda R(w)$. L2 achica todos los pesos, L1 lleva algunos a cero; dropout regulariza apagando neuronas al entrenar.

Medir un clasificador

Separador: medir un clasificador.

El 99% de accuracy que no sirve

Un detector de fraude que siempre dice “no” logra 99% de accuracy y 0% de fraudes detectados. Con clases desbalanceadas, accuracy engaña.

Palabras clave

La matriz de confusión

Matriz de confusión 2×2: TP, FP, FN y TN. Separa los tipos de error; accuracy es solo la diagonal.

Palabras clave
Matriz de confusión (y accuracy)

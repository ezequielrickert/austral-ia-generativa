RAG en tres pasos

Clave para el examen

RAG indexa offline y en cada consulta recupera fragmentos y los concatena al prompt, sin tocar pesos. Una ventana enorme no lo reemplaza: el modelo se pierde en entradas largas.

MCP: el protocolo

Separador: empieza la sección «MCP: el protocolo».

MCP conecta modelos con herramientas

MCP estandariza cómo una app de IA pide datos y acciones: el servidor expone tools, recursos y prompts; el cliente los consume; el modelo elige leyendo descripciones.

Palabras clave
MCP (Model Context Protocol)Uso de herramientas (tool calling)
Relacionadas
09·47MCP: host, cliente y servidorhost, cliente y servidor

M×N conectores, o M+N piezas

Clave para el examen

Sin protocolo, M apps × N fuentes = M×N conectores; con MCP, M+N. HTTP no trae descubrimiento (‘¿qué sabés hacer?’) y GraphQL no ejecuta acciones.

Palabras clave
MCP (Model Context Protocol)

JSON-RPC 2.0: la capa de mensajes

Clave para el examen

MCP usa JSON-RPC 2.0: tools/list y tools/call, un id que aparea pedido y respuesta, result o error. La sesión MCP tiene estado; JSON-RPC no.

Palabras clave
JSON-RPC 2.0MCP (Model Context Protocol)

Herramienta hardcodeada o servidor aparte

Tool hardcodeada: se conoce al compilar y se copia entre agentes. Servidor MCP: proceso aparte, descubierto en ejecución. Con stdio el cliente lanza el subproceso: no hay puerto.

Palabras clave
MCP (Model Context Protocol)stdio

El ciclo de vida de una herramienta

Ciclo: registrar, descubrir con tools/list, elegir, llamar. El modelo elige leyendo la descripción: escribirla es diseño, no documentación.

Tres caminos: extensión de escritorio, configuración stdio (command/args) o servidor HTTP (URL). Un servidor MCP corre con tus permisos: instalarlo es un riesgo.
